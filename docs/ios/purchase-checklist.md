# iPhone 8 采购一页清单（可直接发给卖家）

> 这份是 [device-spec.md](device-spec.md) 的**精简可执行版**：只留"买之前必须确认的事"。
> 完整依据、来源与性质标注在 device-spec。

## 一、买什么

| 项 | 要求 |
|---|---|
| 机型 | **iPhone 8**（`iPhone10,1` / `iPhone10,4`）。**iPhone 8 Plus（3GB 内存）更好**，同一颗 A11、越狱能力完全相同 |
| **iOS 版本** | **必须 ≤ 16.6.1**（最优先，其余都可商量） |
| 激活锁 | **必须无**（有锁 = 砖，直接不要） |
| 成色 | 电池健康 ≥80%；**屏幕最好原装**；Lightning 口能连电脑；**Wi-Fi 必须正常** |
| 容量 | 64GB 起就够（SDK+工具链约 1GB，飞书约 1GB） |

### ⛔ 三条红线（碰到就别买）

1. **iOS 16.7.x 及以上** —— 不是不能越狱，而是**用不了 TrollStore**，Dopamine 得每 7 天用电脑重签一次；
   而 Apple 只签 16.7.16，**买回来退不回 16.6.1**（除非卖家当年存过该机 blobs）。
2. **有激活锁 / iCloud 锁**，或卖家不肯当面抹机重激活。
3. **换过屏**（尤其便宜屏）—— cfw.guide 明确警告：越狱用户态重启后**触摸可能失灵**。

```
   ⚠️ iOS 版本必须 ≤ 16.6.1（16.7 及以上的不要）。
   ⚠️ 请千万不要帮我升级系统，也不要帮我更新到新版本。

2. 必须是「无激活锁 / 无 ID 锁」的机器：
   希望当面「抹掉所有内容和设置」后联网激活一次给我看，能正常激活我就付款。

3. 屏幕要是原装的（换过屏的不要）；电池健康希望 80% 以上；
   能正常连电脑（Lightning 口正常）；Wi-Fi 正常。

4. 想问一下：这台机器的 SHSH2 blobs（按 ECID 存的）当年有没有保存过？
   如果有，我想一并要过来。

5. 不需要你帮我越狱，我会自己弄。请不要在机器上装任何东西、也不要用你的
   Apple ID 登录。
```

> **第 5 条很重要**：见 §四「要不要让贩子先帮我越狱」。

## 三、到手当面/收货前验收（界面即可，5 项）

| 顺序 | 看什么 | 期望 |
|---|---|---|
| 1 | 设置 → 通用 → 关于本机 → **iOS 版本** | **≤16.6.1**（这是第一优先，别的都能谈） |
| 2 | 同上 → 型号名称 / 型号号码 | iPhone 8 / 8 Plus；`M` 开头为零售机（`N` 官换 / `F` 官翻，可用但知悉） |
| 3 | 设置顶部 | **没有登录别人的 Apple ID** |
| 4 | 设置 → 电池 → 电池健康 | ≥80% |
| 5 | 原彩显示能否开关；触摸全区域正常 | 能开关 = 大概率原装屏 |

## 四、要不要让贩子先帮我越狱？——**不要**，但让他做三件事

**结论：越狱这一步你自己做。** 理由：

| # | 理由 |
|---|---|
| 1 | **我们真正要的是"版本对"，不是"已越狱"**。一台 16.7.16 的已越狱机对我们**价值更低**（无 TrollStore，7 天重签）；而一台干净的 ≤16.6.1 才是目标。让他越狱容易把注意力从版本上带偏 |
| 2 | **侧载要绑 Apple ID**。Dopamine 在 ≤16.6.1 上虽然是 TrollStore 永久签名，但**第一次安装仍要签一次名**；让他用自己的账号签，后续出了问题（过期、要重装）还得找他 |
| 3 | **来路不明的越狱环境不可信**。测试机是用来验证"伪造 BSSID"的工具，环境里多一个未知源/未知 tweak，可能干扰我们的验证结果，也可能有安全风险。我们要一份**自己做的、已知干净**的越狱 |
| 4 | **你反正要反复做**。开发过程中要重启、重装、重签、抓栈 —— 让他做一次省不了任何事 |
| 5 | **不好验机**。已经越狱的机器，你很难确认它原本是不是被动过系统或改过版本 |

**该让贩子做的三件事**（都已写进 §二那段话）：

1. **拍「关于本机」截图**，并**保证不升级系统**（版本是唯一不可逆的约束）；
2. **当面抹机 + 联网重激活**，证明无激活锁；
3. **问有没有该机 ECID 的 SHSH2 blobs** —— 有的话将来能降级，价值很高。
